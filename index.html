    PROJETS

    Quixo

    Programme développé avec python. Il permet de jouer au jeu Quixo contre une IA via un serveur en ligne, incluant la gestion du plateau, la saisie des coups, et l’affichage en ASCII.

    Gestion comptes bancaires

    Projet en C++ de gestion de comptes bancaires avec iu crée avec Qt. Le programme permet d’ajouter, modifier et consulter différents types de comptes bancaires, de calculer les intérêts et de sauvegarder les données dans des fichiers, tout en assurant la validation des opérations.

    HeatMyFloor

    Développé en Java avec Swing, HeatMyFloor est une application qui permet de planifier et modéliser l’installation de planchers chauffants de manière intuitive et sécurisée. L’utilisateur peut créer des pièces de forme quelconque, ajouter des meubles, des éléments chauffants, etc. Ce projet sera mis disponible bientôt une fois complété.

    Floppy Fish

    Jeu inspiré de Flappy Bird, dans lequel le joueur contrôle un poisson qui nage dans l’eau plutôt qu’un oiseau qui vole. Le jeu a été développé avec Unity et C#, puis déployé en WebGL sur GitHub Pages. Il est jouable directement dans le navigateur via le lien GitHub Pages.
